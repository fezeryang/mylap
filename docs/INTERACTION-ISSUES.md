# 3D 屏幕视角脱离问题记录

## 状态

- **状态：** Open
- **发现日期：** 2026-09-13
- **范围：** 根 3D 工作区中的收音机与手机屏幕
- **优先级：** P1（破坏设备与屏幕的空间对应关系）
- **来源：** 在线人工反馈

## 问题描述

在设备聚焦或场景旋转时，收音机的两个 CSS3D 屏幕以及手机的 3D 屏幕没有始终贴合设备本体。
当镜头转离设备正面、绕到侧面或背面后，屏幕内容可能继续显示在视野中，表现为屏幕悬浮、偏移，
或与设备外壳脱离。该问题不是设备模型材质或几何问题，而是屏幕 DOM 层与设备空间姿态的同步问题。

## 复现步骤

1. 启动根工作区，进入 Overview。
2. 点击收音机进入 Focus，或点击手机进入 Focus。
3. 在 3D 画布中拖动旋转视角，使镜头从设备正面转向侧面、背面，再转回正面。
4. 观察收音机的 tuner / cassette 两个屏幕，或手机主屏幕。

## 实际结果

- 屏幕内容在设备离开视野或屏幕平面背向镜头后仍可能留在画面中。
- 屏幕投影位置与硬件玻璃区域不一致，出现悬浮或漂移。
- 手机屏幕也有同类现象；旋转设备后，屏幕层没有稳定地跟随外壳。

## 预期结果

- 屏幕始终以设备的真实世界坐标、旋转和缩放为基准。
- 屏幕平面背向镜头、被设备自身遮挡或离开视锥时，应隐藏或被正确裁切。
- 收音机两个屏幕和手机屏幕在正面、侧面、背面旋转后都不应脱离对应硬件。
- 修复不能修改手机、收音机的模型几何、材质、颜色、比例或灯光。

## 可能相关的实现边界

- `src/runtime/screen-runtime.ts`：CSS3D 屏幕的空间变换、朝向、可见性和遮挡判断。
- `src/assets/ratio-asset.ts`：收音机两个只读屏幕的屏幕姿态适配。
- `src/assets/phone-asset.ts`：手机屏幕锚点和深度偏移。
- 当前收音机使用 camera-facing billboard 作为显示补偿；需要确认该策略在镜头绕行时不会造成
  屏幕脱离硬件。

## 后续验收标准

- 分别对收音机和手机完成正面、左右 90°、背面和斜向视角检查。
- 设备旋转与相机旋转过程中，屏幕投影矩形始终落在对应玻璃区域内，或在不可见时完全隐藏。
- 屏幕不会在设备外部留下可见或可交互的悬浮层。
- 3D 模式与独立展开窗口仍使用同一应用状态；修复不改变硬件视觉资产。
