# TODŌU：流畅交互与设备内浏览 PRD

## 目标与已确认取舍

在 V2 现有系统上演进，不重做设备，不改变几何、材质、颜色、灯光、阴影和像素密度。
消除手机漏点及静止场景的无效工作，让电脑与手机在设备内部访问个人网站。
增加完整的浏览器标签和共享下载能力，不把外部浏览器弹窗伪装成设备内功能。

## 用户流程

1. Overview 点击屏幕先聚焦设备；镜头停稳后，单次点击立即打开应用。
   输入、滑动、音量拖动接管屏幕输入，不驱动场景旋转；展开与 3D 保留同一应用树。
2. 「我的网站」快捷入口打开或激活个人网站标签；首页、作品、博客、关于在屏幕内浏览。
   手机与电脑各有标签和历史，共享收藏。新建、关闭、切换、前进、后退、刷新、停止均可用。
3. 网站下载、照片和录音保存、笔记导出首先进入共享「文件 / 下载」。
   文件可预览、重命名、删除并明确选择「导出到此电脑」；刷新后仍保留。
4. 实体收音机保留造型，播放、暂停、停止和换台可直接点击；只读屏幕不挡住实体控制。

## 技术与安全边界

- 单一按需渲染调度：镜头、键盘和收音机动画期间连续，静止及展开屏幕时停止隐藏的 WebGL 工作。
  缓存其他设备遮挡候选和变换；避免每帧六次全模型射线检测及重复 DOM 状态写入。
- 浏览器会话按设备实例存储。当前标签独占 iframe，后台仅保留地址和可恢复滚动。
- 个人网站 `https://home.fezern8n.com` 使用可信跨源 iframe；不授权顶层导航或弹窗。
  双向桥验证精确 origin、source、版本和消息字段，普通独立网站访问不受影响。
- 下载保存到独立 IndexedDB 命名空间；单文件上限 50 MB。显示真实进度，支持取消、重试、
  存储失败反馈；不绕过第三方网站 CSP/CORS，不获取用户账户或凭据。
- 个人网站桥接在其独立仓库实施，本地双站联调；未部署时明确区分本地与线上能力。
