# TODŌU Interactive Workspace V2 产品需求文档

版本：2026-09-13 · 状态：本轮已实现，可本地体验

## 1. 目标与范围

在现有 3D 桌面中，把电脑、手机和收音机的软件体验推进为可日常操作的个人工作区。
电脑借鉴 macOS 的窗口、Dock、菜单与快捷操作；手机借鉴 iOS 的主屏幕、应用切换、
控制中心和内容层级。所有展示为操作入口的按钮必须执行真实动作，并反馈结果。

保留电脑、手机、收音机与桌子的模型、材质、颜色、比例和灯光。
允许修正 DOM 屏幕的锚点映射、尺寸、安全区与裁切；不通过修改外壳适配 UI。
本轮不接入 Apple 原生软件、Apple ID、付费媒体库、云端账号或真实 AirPlay 协议。
数据联动指同一网页内的虚拟设备；持久化使用当前浏览器本地存储。

## 3. 核心用户路径

1. 点击电脑，打开备忘录编辑；切到展开窗口后继续输入，收起后内容与窗口状态保持。
2. 在手机导入照片；在电脑打开照片应用查看同一张图片、放大、下载或删除。
3. 用户主动授权麦克风，开始录音、暂停/继续、停止；录音出现在共享列表，可播放、重命名、下载、删除。
4. 电脑设置倒计时后切到手机，看到同一剩余时间；暂停、继续、重置均同步，页面后台返回仍准确。
5. 左副屏播放本地音乐或电台；手机快捷控制可暂停/调整音量，电脑主屏即时反映变化。
6. 右副屏查看当天日程并完成待办，电脑和手机中的原应用同步更新。
7. 手机从真实模型屏幕进入应用，再切到独立窗口；无溢出、拉伸、上下颠倒或交互错位。

## 4. 详细需求与验收

### P0：手机屏幕贴合

- 核对物理 screen anchor、平面方向、DOM 宽高、CSS3D 单位缩放与圆角。
- 3D 模式保持物理屏幕纵横比，展开模式使用相同应用树并响应新尺寸。
- 状态栏、动态岛、底部手势区不能遮挡应用内容或穿出屏幕。
- 手机应用采用单列导航；增加应用后主屏可滚动，Dock 与返回入口仍可用。
- 验收：Overview、手机聚焦、展开与收起四种状态检查边界；实际点击、输入及滚动无偏移。

### P0：真实媒体操作

- 播放/暂停、上一首/下一首、进度与音量必须作用于真实媒体元素。
- 清晰区分本地音乐与在线电台，空媒体库提供导入入口；目录失败可重试。
- 快捷播放在选中电台后应处理开机，而不是要求用户猜测前置开关。
- 播放失败、浏览器拦截、无电台或不支持格式显示可理解的信息；不得伪装“正在播放”。
- 物理收音机和屏幕中的控制继续使用同一个电台服务，不复制播放器状态。
- 增加循环/随机等操作时，必须改变实际下一首选择逻辑。
- 验收：导入音频播放，在另一虚拟设备暂停；切换电台与音量同步；空状态及加载失败可恢复。

### P1：新增照片应用

- 电脑与手机共享照片库；用户本地选择图片导入，支持多选。
- 缩略图网格、单张预览、上一张/下一张、放大、文件信息、下载与确认删除。
- 原文件保存在 IndexedDB，刷新后可读取；限制类型与单文件大小并说明错误。
- 不上传用户图片；不预置冒充用户照片的假内容。
- 验收：手机导入→电脑查看→下载内容一致→重新打开仍存在→删除同步。

### P1：新增语音备忘录

- 通过 MediaRecorder 真实录制麦克风音频；仅点击录音后请求权限。
- 显示录音状态与实际时长；支持暂停、继续、停止保存及取消。
- 录音列表支持播放/暂停、重命名、下载与确认删除，两端共享并持久化。
- 权限拒绝、无麦克风、浏览器不支持及空间不足均反馈；停止或取消后释放麦克风。
- 验收：真实媒体管线录制→保存→播放→跨设备看到同一记录；拒绝权限不破坏其他应用。

### P1：新增时钟应用

- 世界时钟展示若干城市的真实时间与时区。
- 秒表开始/暂停/复位、计圈；倒计时支持时长输入、开始/暂停/继续/取消及结束提示。
- 同一服务承载两个设备的活动计时，窗口关闭/设备切换不重置倒计时。
- 根据绝对时间计算，避免后台标签页降频造成累计误差；刷新恢复有效倒计时。
- 验收：两端计时一致、暂停不继续走时、结束只产生一次状态转换、重开恢复。

### P1：电脑主屏与手机系统交互

- 所有新增应用进入电脑 Dock/搜索及手机网格/应用搜索，图标清晰、名称明确。
- 电脑增加窗口总览/切换和键盘可达的关闭、最小化、搜索；保留浏览器常用快捷键。
- 控制中心提供有效的媒体控制、明暗外观、减少动画与设备跳转；不增加假 Wi-Fi/蓝牙/电量。
- 手机动态岛显示当前真实媒体信息与播放状态，可点击或键盘展开，支持播放/暂停及进入音乐。
- 手机最近应用保持状态；底部手势有原生按钮作为替代，编辑文字时不误触导航。
- 验收：鼠标、键盘、触屏等效入口可用，关闭覆盖层恢复焦点，主题同步不改变硬件。

### P1：左副屏「播放台」

- 为现有副屏逻辑尺寸独立布局：紧凑标题、当前播放内容、进度/直播标识、大尺寸播放控件。
- 资料库/电台切换，音量、上一首/下一首或换台、可展开查看。
- 小屏优先显示正在播放与核心操作，不塞入完整资料库首页和长说明。
- 与主屏、手机及收音机共享媒体服务；完整内容管理继续在主屏音乐应用完成。

### P1：右副屏「今日」

- 顶部日期时间、中部日程与待办、底部快速添加待办/设备入口。
- 支持勾选完成、快速添加，空状态邀请真实输入；条目较多时内部滚动。
- 紧凑布局适配副屏，不改变副屏锚点、尺寸或外壳。
- 验收：添加或完成待办可在手机立即观察；当日日程与日历一致。

## 5. 技术实现与数据边界

- 保持 Vite + TypeScript + Three.js + 原生 DOM 的现有架构，不引入第二套 UI 框架。
- `src/apps/` 拆分可独立挂载的软件及紧凑控制；主机统一创建、注入并销毁共享服务。
- 新照片/录音服务负责 Blob 存储与资源生命周期；计时服务负责时间状态。
- 保留原数据存储键与版本迁移逻辑，新增数据使用独立命名空间，不清空现有笔记和音乐。
- 图片 URL、录音流、Audio、定时器、订阅在适当生命周期释放；无密码、密钥或外部上传。
- 不写入模型生成目录、历史参考目录及 AGENTS.md；不覆盖另一会话的整改文档。

## 8. 本轮交付与体验入口

打开 `http://localhost:5173/`，使用当前根项目；`phone/` 等独立建模入口不是本轮软件系统。
点击设备进入，屏幕中的「展开 ↗」切换为独立窗口，同一应用树和数据继续保留。

- **电脑 / 手机**：共 11 个应用，新增照片、语音备忘录和时钟，保留原有八个应用。
  新应用均接入电脑 Dock、手机应用网格和全局搜索（Ctrl/Cmd+K）。
- **照片**：真实导入、解码、缩略图、预览、缩放、原图下载和确认删除；IndexedDB 保存。
- **录音**：主动授权后录制、暂停、继续、保存、回放、重命名、下载和删除。
  切换应用不丢弃正在录制的内容，停止/取消释放麦克风；实体 REC 键打开语音备忘录入口。
- **时钟**：真实世界时间、秒表计圈和共享倒计时，支持暂停、继续与恢复。
- **媒体 / 副屏**：用户视角左侧为播放台、右侧为今日；共享本地音乐和电台控制。
  物理播放、暂停、停止、换台和音量入口作用于同一个电台服务；手机动态岛显示实际媒体状态。
- **系统操作**：电脑窗口总览、Dock 右键菜单、控制中心；Alt+W 关闭窗口、Alt+M 最小化、
  Alt+方向右键切换窗口。手机底部上划进入最近应用，也保留原生按钮入口。
- **显示修正**：手机逻辑尺寸与玻璃比例一致，DOM / 点击平面移到玻璃前侧；仅调整手机聚焦镜头
  使文字正向可读。修复展开窗口继承 3D 镜头变换、浅色主题变量缺失和玻璃面板文字对比度问题。
  屏幕内覆盖层优先处理 Escape，之后再释放设备输入焦点。硬件几何、材质和灯光未改动。
